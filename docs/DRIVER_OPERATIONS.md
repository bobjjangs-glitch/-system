# Android 1.6.0(16) 운행·도착 확인·기사별 내역

운행 중 Home·화면 잠금·최근 앱 목록에서 닫아도 위치 서비스를 유지하도록 `killServiceOnDestroy: false`로 변경했습니다. 실행 중인 이전 등록의 true 설정은 앱이 열린 상태에서 안전한 시작 절차를 거쳐 갱신합니다. 기존 위치 서비스 시작 오류 처리와 권한 검사를 보존하고, 일시적인 위치 공급자 오류만으로 영구 종료하지 않습니다. 느린 연결에서는 GPS를 모두 쌓지 않고 최신 대기 위치를 전송합니다.

**휴대폰 설정:** 바른배차의 위치를 ‘항상 허용’, 정확한 위치·알림을 켭니다. Galaxy A16은 앱 정보 → 배터리 → ‘제한 없음’을 확인합니다(기종/OS에 따라 메뉴명이 다를 수 있습니다). 기사 화면의 ‘휴대폰 앱 설정 열기’로 이동할 수 있습니다. 운행 출발·위치 공유 시 앱을 화면에 열어 두고 권한 요청을 완료하세요.

Android 설정의 **강제 중지**, 휴대폰 재부팅, OS가 메모리/배터리 등의 이유로 서비스를 종료한 경우 지속 수신을 보장하지 않습니다. 다시 앱을 열어 위치 공유 상태를 확인하고 켜야 합니다. 이 변경은 OS 제한을 우회하거나 부팅 후 무단 시작하지 않습니다. 서버 연결이 없거나 세션이 만료되면 실시간 전송할 수 없습니다. 관리자 지도는 마지막 수신 시각과 오래된 위치 상태를 구분합니다.

## 배송지 도착 → 확인 → 다음 코스

위치 오차 50m 이내, 배송지 반경 80m 안에서 30초 이상 낮은 속도로 머문 현재 배송지를 확인 대상으로 삼습니다. GPS 도착 감지는 **배송 완료 API를 호출하지 않습니다.** 이전 자동 완료의 미확인 요청을 업데이트 후 재전송하지 않습니다.

1. 앱 화면을 보는 중이면 ‘배송완료하겠습니까?’ 확인창을 표시합니다.
2. 외부 내비 사용·화면 잠금 중이면 높은 중요도의 ‘배송지에 도착했습니다’ 알림을 표시합니다. 알림 또는 ‘배송 완료 확인’을 누르면 앱에서 확인창을 엽니다. 다른 앱 위로 전체 화면 창을 강제로 띄우지 않습니다. 휴대폰의 알림/방해금지 설정에 따라 팝업 표시가 달라집니다.
3. 거래처·주소·물품·수량을 확인하고 **배송 완료**를 누르면 서버에 저장합니다. 실패하면 확인창을 유지하고 오류를 표시합니다. 응답 유실은 해당 코스/배송지의 저장 상태를 재조회하여 확인하고, 중복 클릭을 막습니다.
4. 저장이 확인되면 **다음코스로 이동할까요?**를 표시합니다. **네 · 네이버 길안내**를 누르면 최신 남은 코스를 조회해 네이버를 엽니다. 설치 앱은 기존 공식 경유지 한도 안에서 남은 코스와 회사 복귀를 이어 주고, 웹은 다음 주소의 네이버 검색을 엽니다. 네이버 앱 설치가 필요합니다.
5. **아니오 · 잠시 대기**는 자동으로 지도를 열지 않습니다. 이후 기사 화면의 길안내를 눌러 이어갈 수 있습니다. 마지막 배송 뒤에는 회사가 목적지입니다.

‘아직 배송 중’을 누르면 즉시 반복해서 묻지 않도록 2분 유예합니다. 같은 위치의 다음 배송지에는 연쇄 처리를 막는 출발 확인이 적용되므로 현재 배송지의 ‘배송 완료 확인’을 직접 사용할 수 있습니다. GPS 확인은 보조 기능이며 운전 중 화면을 조작하지 말고 안전하게 정차한 뒤 처리하세요.

새 APK로 업데이트해야 기존 GPS 자동 완료가 확인 방식으로 바뀝니다. 서버 업데이트만으로 이전 APK 내부 코드를 바꿀 수 없습니다. 기존 앱과 같은 서명으로 덮어 설치할 수 있습니다.

## 관리자 지도와 내역

기사 마커는 흰 테두리가 있는 큰 차량 아이콘과 기사 이름을 표시하고 배송지 핀 위에 놓습니다. 최근 위치는 맥동, 오래된 위치는 회색으로 구분하고 클릭하면 수신 경과 시간을 볼 수 있습니다. 수신만으로 사용자가 조정한 지도 확대/이동을 초기화하지 않습니다. 같은 곳에 여러 기사가 있으면 기사 선택으로 위치를 구분할 수 있습니다.

‘내역’은 기사별 전체·완료·미배송·대기 건수와 물품 총 수량을 먼저 표시합니다. 기사 선택·펼치기, 상태 필터, 거래처/주소/물품/판매번호/연락처 검색을 지원하며 배송 상세로 열 수 있습니다. 미배차와 기사 확인 필요 내역은 별도로 표시합니다. 날짜별 업로드 원본 내역은 계속 제공합니다.

## 기본 엑셀 업로드 개선

- 처음 30행에서 제목을 찾고 표지가 있으면 자료 시트를 읽습니다. 배송주소를 일반 ‘주소’보다 우선하여 공급자 주소를 배송지로 잘못 넣지 않습니다. 구분할 수 없는 중복 제목은 오류로 알립니다.
- 품명/품명 및 규격/품목명, 별도 규격·품목코드, 연락처와 전표번호를 읽습니다. 서로 다른 전표번호는 같은 거래처·주소라도 합치지 않습니다. 같은 전표의 품목은 묶고 합계·소계 행은 제외합니다.
- 기본 CSV도 UTF-8/BOM, UTF-16LE, 한국어 CP949를 지원합니다. 알려진 단위 ‘개/본/짝/EA’가 붙은 숫자 수량을 읽습니다.
- 없는 거래처·품목명·수량을 임의로 채우지 않습니다. 수량 누락은 검토 화면에서 0과 경고로 표시하며 실제 값을 입력해야 저장됩니다.
- ‘판매번호/일자-No.’와 거래처·수량 열이 있는 판매조회 형식은 기본 업로드에서도 감지해 선택한 배송일의 전표를 읽습니다. E카운트 검색 자료와 연결하고 날짜·중복 검사를 유지합니다. 실제 계정에 직접 로그인하는 API 연결은 아닙니다.
- 원본에 주어진 금액을 사용하며 단가나 세율을 임의로 추정하지 않습니다. 인쇄 양식을 그대로 그린 Excel이나 구분되지 않는 공급자/고객 표는 평면 자료 열로 정리해야 할 수 있습니다.

이번 사용자의 실제 문제 Excel 파일은 제공되지 않았습니다. 제목/공급자·배송주소/전표번호·품목·수량이 섞인 합성 파일과 실제 로컬 업로드 API로 수정 동작을 검증합니다. 실제 Galaxy A16의 장시간 위치 수신·네이버 앱 전환은 단말 검증이 추가로 필요합니다. 테스트와 APK 포함 여부 검증을 실기기 검증으로 표시하지 않습니다.

앱과 서버를 모두 업데이트합니다. Render `codex/free-node-test` 최신 커밋을 수동 배포하기 전에 무료 서버의 임시 `/tmp` 내역을 백업하세요. 기존 계정·전표·운행 기록을 초기화하는 DB 변경은 포함하지 않습니다.
