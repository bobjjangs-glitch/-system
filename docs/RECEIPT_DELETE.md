# 잘못 올린 전표와 배송지 삭제

관리자 `전표 → 기기에 저장된 전표`, `확인을 기다리는 업로드`, `내역 → 업로드 내역`의 **전표 삭제** 또는 전표 확인 화면의 **이 전표 삭제**를 누릅니다. 확인 창에서 파일 이름과 삭제 범위를 확인하고 **삭제하기**를 누르면 처리됩니다.

- 아직 서버에 저장하지 않은 기기 전표는 앱 전용 초안과 사진 복사본을 지웁니다. 휴대폰 갤러리에 있는 원본은 보관됩니다.
- 서버에 올린 검토 전표는 업로드 내역과 원본을 삭제합니다. 연결된 기기 초안은 서버 삭제가 성공한 뒤 정리합니다.
- 이미 등록한 전표는 연결 배송지가 모두 미배차 상태일 때만 삭제할 수 있습니다. 전표 한 건과 해당 전표의 미배차 배송지가 함께 삭제됩니다. 배차·운행·완료·미배송 처리한 내역이 하나라도 있으면 서버가 변경 없이 거부하고 확인 창에 이유를 표시합니다.
- 배송지 한 곳만 지우려면 관리자에서 해당 배송 상세를 열고 **이 배송지 삭제**를 누릅니다. 미배차 배송지만 가능하며 전표 원본과 다른 배송지는 보관됩니다. 등록하기 전 전표 확인 화면에서는 배송지가 여러 곳일 때 각 행의 휴지통으로 해당 행만 제외할 수 있습니다.

확인 창을 연 동안 저장과 삭제가 동시에 실행되지 않으며, 삭제 중에는 반복 실행과 창 닫기를 막습니다. 다른 전표·기사 PIN·코스는 유지됩니다. 삭제한 내용은 복구할 수 없습니다. 새 APK와 `DELETE /api/imports/:id`가 포함된 서버 버전을 함께 사용합니다.

서버 자동 테스트 `server/tests/receipt-delete.test.ts`는 권한, 전표 한 건만 삭제, 연결된 미배차 배송지 삭제, 사용 중인 전표 거부, 기기 재업로드 매핑 정리, 원본 유실·정리 실패·업로드 폴더 경계 보호를 확인합니다. 실제 휴대폰의 촬영·갤러리 원본 보존 및 확인 창 동작은 설치 후 확인합니다.
