# 주소로 길찾기·개별 배차·배송지 삭제

Android 1.4.4부터 관리자는 주소만 입력합니다. 회사·전표 화면과 새 엑셀 양식에는 위도·경도 입력란이 없습니다. 위치 값은 지도와 코스 계산을 위해 서버 내부에서 관리합니다.

## 등록과 주소 확인

사진·엑셀 인식 결과의 거래처, 배송주소, 물품·수량을 확인하고 저장합니다. 저장한 미배차 배송지는 백그라운드에서 주소를 조회하며, 등록과 다음 전표 촬영을 오래 기다리게 하지 않습니다. 개별 기사 배정·추천 배차·길찾기를 누를 때도 빠진 위치를 자동 확인합니다. `배차 → 등록한 배송지 주소 확인`은 한 번에 최대 25곳을 조회하며 남은 주소가 있으면 다시 실행할 수 있습니다. 잘못된 주소나 응답으로 임의 위치를 만들지는 않습니다.

주소가 변경된 동안 이전 조회가 끝나도 오래된 결과로 덮어쓰지 않습니다. 주소를 찾지 못하면 도로명·건물번호를 확인하고, 관리자에게 표시된 서비스 설정·인증 오류를 처리합니다. 숫자 위치를 직접 입력할 필요는 없습니다.

## 개별 기사 배정

`배차 → 미배차 배송지 → 배송 상세 → 기사 배정`에서 기사를 선택합니다. 활동 중이며 정원이 남은 기사에게만 배정할 수 있습니다. 기존 출발 전 코스가 있으면 그 코스에 추가하고 배송 순서·예상 시간·회사 복귀를 다시 계산합니다. 없으면 새 코스를 만듭니다. 운행·복귀 중인 기사에게 추가 배정하지 않습니다.

개별 코스에는 `개별 배차`가 표시됩니다. 추천 배차는 이 코스와 기사 배정을 보존하고 다른 기사들에게 남은 배송지를 배정합니다. 개별 배차 기사의 남은 정원에는 추가 배송지를 다시 개별 배정할 수 있습니다. 회사 출발·복귀 주소를 변경하면 출발 전 배차는 다시 구성해야 합니다.

## 주소 길찾기

배송 상세의 `주소로 길찾기`를 누르면 주소를 내부에서 확인한 뒤 회사에서 선택한 네이버·카카오 등 내비를 엽니다. 이미 확인한 위치는 재조회하지 않습니다. 휴대폰 앱의 네이버 안내는 공식 navigation URL을 사용합니다. 브라우저의 네이버·카카오 연결은 배송주소 검색을 엽니다.

주소 서비스 확인이 실패하면 명시적으로 Google 지도의 주소 길안내 또는 네이버·카카오 주소 검색을 선택할 수 있습니다. 선호 지도를 몰래 바꾸거나 잘못된 위치로 내비를 열지 않습니다. 이 기능은 개별 배송지 길찾기이며, 외부 내비의 연속 경유지 한도는 [CONTINUOUS_DRIVING.md](CONTINUOUS_DRIVING.md)를 따릅니다.

## 저장된 배송지 삭제

관리자 배송 상세의 `이 배송지 삭제`에서 확인 후 삭제합니다. 미배차 배송지와 아직 출발하지 않은 코스의 배송지를 삭제할 수 있습니다. 출발 전 배차에서 한 곳을 지우면 나머지 순서를 유지하면서 회사 왕복·체류 시간·예상 도착 시간을 다시 계산합니다. 마지막 배송지를 지우면 빈 코스도 정리합니다. 전표 원본과 다른 배송지는 보관합니다. 운행·복귀·완료 기록과 배송 완료·미배송 처리 내역은 이 기능으로 지우지 않습니다.

## 주소 검색 서버 설정

Naver Cloud Maps Application에서 **Geocoding**을 활성화합니다. 관리자 웹 지도 Key ID만으로 서버 주소 검색을 인증할 수는 없습니다.

- `NAVER_GEOCODING_KEY_ID`, `NAVER_GEOCODING_KEY_SECRET`: 주소 검색 전용 인증. 둘 다 있어야 합니다.
- 전용 인증을 생략하면 기존 `NAVER_DIRECTIONS_KEY_ID`, `NAVER_DIRECTIONS_KEY_SECRET`를 재사용합니다. 그 Application에도 Geocoding을 활성화해야 합니다.
- 네이버 서버 인증이 전혀 없을 때만 `KAKAO_REST_API_KEY`, 그마저 없으면 공개 Nominatim을 사용합니다. 공개 검색은 요청마다 1.1초 간격을 두며 한국 건물 주소를 찾지 못할 수 있습니다.

인증 실패·할당량·검색 실패·서비스 지연은 구분해 표시합니다. 실패한 유료 공급자를 다른 결과로 바꾸지 않습니다. 서버 인증 비밀값을 채팅·앱·`EXPO_PUBLIC_*`에 넣지 마세요. 공식 문서는 https://api.ncloud-docs.com/docs/application-maps-geocoding 입니다.

새 APK와 서버를 함께 업데이트합니다. Render 수동 배포는 임시 `/tmp`의 기록을 초기화할 수 있으므로 필요한 내역을 먼저 보관하세요. 이 변경의 DB 처리는 기존 계정·전표·운행 기록을 삭제하거나 초기화하지 않습니다.
