# 오늘 판매내역 자동 조회 — 1.14.0(24)

관리자 **전표** 화면을 열면 날짜나 전표번호를 입력하지 않아도 한국 시간의 오늘 판매내역을 회사 ERP에서 자동으로 읽습니다. 예를 들어 한국 날짜가 2026-11-09이면 `2026-11-09`로 조회하며, 해당 일자에 20건이 있으면 전체 20건을 표시합니다. 예시 날짜를 앱에 고정하지 않습니다.

## 조회하고 전표에 넣기

1. **전표** 화면에서 **오늘 판매조회** 목록을 확인합니다. 거래처·품목 목록도 자동 갱신합니다. 화면에 표시된 회사 ERP 주소로 현재 조회 대상을 확인할 수 있습니다.
2. 판매내역 카드를 누르면 선택한 원본 문서 ID로 현재 버전과 마지막 수정본을 다시 읽습니다. 같은 표시 번호의 다른 원본이나 변경된 번호를 임의로 고르지 않습니다.
3. 판매전표 확인 화면에 공급자·거래처·주소·연락처·계좌·잔액·기재 사항 등 원본 헤더와 품목·규격·수량·단가·공급가액·부가세·합계·공장도가·DC율·적요·DOT가 자동으로 채워집니다. 휴대폰에서는 세로 카드로 확인합니다.
4. 배송 정보를 확인하고 **확인하고 전표 등록**을 누릅니다. 이때만 앱의 전표와 배송지를 등록하며, ERP 원본 판매·확정·재고를 다시 처리하지 않습니다. 확인 중 원본이 바뀌면 최신 내용을 다시 확인하고, 같은 원본의 중복 등록은 막습니다.
5. **등록한 전표로 지역별 배차 추천**으로 구·시·군 기준 배차를 이어갑니다.

목록은 1분마다, 앱으로 돌아왔을 때, 화면이 다시 활성화됐을 때 갱신합니다. 오늘 모드에서 한국 날짜가 바뀌면 새 오늘로 전환합니다. 과거 날짜를 직접 입력한 경우 그 날짜를 유지하며 **오늘 판매내역**으로 오늘 모드에 돌아옵니다. 자동 조회는 조회 JSON 내역이나 배송지를 반복 생성하지 않습니다. 기존의 수동 저장 목록·등록 당시 명세서·내역 삭제 기능은 유지됩니다.

## 전표번호와 연결 확인

`20261106-72`, `26/11/06-72`, `2026/11/06-72`는 같은 날짜·순번의 전표로 검색합니다. 전체 번호를 입력하면 순번 72를 720과 혼동하지 않습니다. 거래처·주소·연락처·품목 검색도 지원합니다. 날짜를 선택하지 않고 **명세서 → 전표번호로 명세서 조회**에서 직접 찾는 기능도 유지됩니다.

연결 대상은 닷홈 자체 ERP의 `dispatch_api.php`입니다. 외부 E카운트 API를 호출하지 않습니다. 자체 ERP 안의 `erp_ecount_*`는 로컬 보관 테이블 이름이며 외부 서비스 연결을 뜻하지 않습니다.

자동 판매조회는 PHP 연동 버전 **1.13 이상**, 원본 자료 구분 `native-archive`, 실제 원본 저장소 `erp_ecount_documents`를 확인한 뒤 전체 페이지를 읽습니다. 구형 PHP가 일반 판매 저장소의 빈 결과를 보내는 경우 이를 정상 0건으로 표시하지 않고 연결 파일·저장소 오류를 안내합니다. 정상적인 원본 저장소가 해당 날짜에 실제 0건을 반환한 경우에만 0건으로 표시합니다. 조회 실패 시 이전 목록은 마지막 조회 자료로 구분하며 최신 정상 결과로 위장하지 않습니다.

## 적용

- Node 서버와 Android 앱을 **1.14.0(24)**으로 갱신합니다. Render 인증·배포는 사용자가 진행합니다. 릴리스에 표시된 `codex/free-node-test` 커밋을 배포하고 같은 릴리스 APK를 설치합니다.
- 이미 자체 ERP PHP **1.13 이상**이 정상 설치됐다면 이 자동 조회 기능 때문에 원래 ERP 편집기·도우미를 교체할 필요는 없습니다. 구형·누락 파일 또는 잘못된 저장소 오류가 나오면 최신 릴리스의 ERP 연동 PHP 7개를 함께 적용합니다. 새 패키지의 연결 버전 표시는 1.14입니다.
- 자동 설치 ZIP을 사용하는 경우 `bareun_update_1_14.php` 하나를 기존 FTP `tire/erp`에 올리고, ERP 관리자로 해당 파일을 열어 **백업하고 ERP 파일 7개 적용**을 누릅니다. 성공하면 설치기는 삭제되고 연결 확인 화면으로 이동합니다.
- 기존 `COMPANY_ERP_API_URL`과 `COMPANY_ERP_TOKEN`을 유지합니다. 실제 회사 URL은 `https://bobjjangs1231.dothome.co.kr/tire/erp/dispatch_api.php`입니다. 키는 서버 환경변수에 보관합니다.

기존 PHP 파일 배치·도우미·원본 ID 진단은 [자체 ERP 원본 연결](ERP_1_13_NATIVE.md)을 참고하세요. 그 문서의 1.13 수동 조회 화면 설명은 이전 버전의 사용 흐름입니다. 현재 자동 조회는 이 문서를 따릅니다.

## 검증 범위

자동 오늘 조회·20건 전체 표시·전표번호 표기 통일·원본 ID 상세와 확인·최신 수정본·중복 방지·자동 갱신의 내역 비생성·0건과 오류 구분을 서버 및 모바일 브라우저 테스트로 검증합니다. 테스트 결과 수와 APK/ZIP 해시는 해당 릴리스의 검증 증거를 따릅니다. 테스트용 외부 ERP 응답이나 가상 DB는 실제 회사 자료 조회와 구별합니다.

실제 운영 ERP의 인증된 자료 조회, 운영 FTP 적용·Render 배포, 실물 휴대폰 카메라·GPS는 각 실행 여부를 별도로 확인합니다. 앱에서 주소가 표시되거나 서버 버전이 맞는 것만으로 실제 회사 전표가 조회됐다고 주장하지 않습니다. 앱에서 보관한 등록 명세서와 중복 기록은 서버 `APP_DATA_DIR`의 저장 자료이므로 운영 서버에서는 영속 저장소로 유지합니다.
