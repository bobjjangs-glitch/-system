# 기사 앱 1.1.0 업데이트

## 전체 코스 지도

기사 화면에서 `전체 경로 크게 보기`를 누르면 회사 출발 → 모든 배송지 → 회사 복귀를 한 화면에서 확인한다. 번호는 배차 순서이며 다음 배송지는 파란색, 완료한 배송지는 회색, 미배송은 빨간색으로 구분한다. 지도 안의 `전체 경로` 버튼은 확대·이동한 화면을 전체 코스에 다시 맞춘다. 도로 경로의 굴곡도 화면 범위에 포함한다.

이 화면은 코스 미리보기다. 미리보기를 열어도 출발·배송 완료 상태를 바꾸지 않는다. 기존의 첫 배송지 길안내, 배송 완료 후 다음 목적지 안내, 마지막 배송 후 회사 복귀 안내는 그대로 제공한다. 점선은 도로 정보를 얻지 못했을 때의 배송 순서이며 실제 도로 경로로 표시하지 않는다.

## 아이콘과 시작 화면

`assets/icon.png`는 배송 차량·상자·경로 핀을 사용한 앱 아이콘이다. Android 아이콘, iOS 아이콘 설정, 웹 파비콘, 로그인 로고와 시작 화면에 사용한다. `expo-splash-screen`으로 네이티브 시작 화면도 같은 녹색 배경에 맞추고, 앱 내부 정보 로딩 중에는 로고와 상태 표시를 보여 준다. 실제 로딩 상태에 따라 다음 화면으로 이동하며 임의의 진행률이나 대기 시간을 추가하지 않는다. 움직임 줄이기 설정을 켰으면 로딩 애니메이션을 반복하지 않는다.

네이티브 모듈과 앱 설정 변경으로 `npx expo prebuild --clean --platform android --no-install`을 실행했다. 기존 테스트 서명 키를 보존해 LDPlayer에 덮어 설치할 수 있게 한다. Android 버전은 1.1.0, versionCode는 2다. iOS 설정도 포함하지만 IPA 서명·컴파일은 이번 Android 작업에 포함하지 않는다.

## 배송 물품과 수량

기사에게 배정된 코스 상단에 `오늘의 배송 물품`을 표시한다. 같은 이름의 품목은 합산하고 총수량·배송지 수·품목 종류 수를 함께 보여 준다. 종류가 많으면 목록을 펼칠 수 있다. 출발 전 상차 수량을 확인하는 전체 배정 목록이며 배송 완료 시 총 상차 수량을 줄이지 않는다.

다음 배송지와 전체 코스의 각 배송지에도 품목명과 수량을 별도 행으로 표시한다. 긴 품목명은 줄바꿈하고 수량을 오른쪽에 고정한다. 관리자와 기사는 같은 배송지의 저장된 품목·수량을 읽는다. 기사가 다른 기사에게 배정된 물품을 조회하는 기능은 추가하지 않는다.

## 위치 공유 검토 범위

서버 테스트에서는 관리자 WebSocket의 좌표 수신, 동시에 운행하는 기사별 좌표 분리, 지연 도착한 좌표 무시, 오래된 좌표 거부, 다른 기사 배송 처리 차단, 회사 복귀 완료 후 위치 업로드 거부를 검증한다. `/api/me`가 기사에게 실제 배정된 품목과 수량을 반환하는지도 확인한다. 모든 검증은 별도 임시 DB를 사용한다.

관리자 지도는 해당 코스가 운행·복귀 중이고 최근 2분 이내 좌표일 때 `위치 수신 중`으로 표시한다. 그 외에는 `마지막 수신 위치`로 표시한다. 좌표 갱신 시 기사 마커를 유지해 열어 둔 정보창이 닫히지 않게 한다. 기사 앱도 코스가 종료됐거나 배정이 없어지면 위치 공유를 정리한다.

브라우저 검증에서는 임시 좌표를 위치 API로 전송해 관리자 화면의 실제 WebSocket 수신과 마커 이동을 확인한다. 지도 UI 검증용 외부 타일은 대체 응답을 사용한다. 이 검증은 실기기 GPS 정확도·백그라운드 권한·화면 잠금 중 위치 전송을 검증한 것이 아니다. Android·iPhone의 실제 운행 검증은 각 기기에서 위치 권한을 허용한 뒤 별도로 수행한다.

## 설치

LDPlayer 9 64비트에는 새 APK를 기존 앱 위에 덮어 설치한다. APK의 앱 ID와 서명 인증서가 기존 파일과 같은지 확인한 뒤 전달한다. 기존 앱을 먼저 삭제하거나 관리자·기사 데이터를 초기화하지 않는다. 서버는 기존 `https://bareun-dispatch-test.onrender.com`을 사용하며 지도 UI가 APK에 포함되어 이 업데이트만을 위해 Render를 재배포할 필요가 없다.
