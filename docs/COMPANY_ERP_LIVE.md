# 회사 ERP 연결

현재 버전 1.12.0(22)의 설치·자동 조회·전체 전표 확인·배차·삭제·OCR 금액 처리는 [최신 사용 안내](ERP_1_12_WORKFLOW.md)를 따릅니다.

회사 ERP는 https://bobjjangs1231.dothome.co.kr/tire/erp/index.php 입니다. 비밀 연결키는 Render 서버의 COMPANY_ERP_TOKEN에만 저장합니다. 기존 키는 재발급하지 않고 사용합니다. 앱에 키를 포함하지 않습니다.

앱에서 기존 판매전표를 조회하고 배송 전표로 등록하는 동작은 ERP 판매·확정·재고를 변경하지 않습니다. 앱의 새 수기 전표 저장은 기존과 같이 ERP 작성중 판매전표를 생성하며, 판매 확정·재고 차감은 ERP에서 진행합니다.
